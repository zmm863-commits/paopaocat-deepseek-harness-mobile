# 泡泡猫 DSH 手机版 v0.23 · 更新说明

> 本版四件事：**会话失败不再吓人（且自动重试一次）**、**左右滑动更跟手**、
> **设置页按你的顺序重排**、**每个模型加「匹配度提示框」**。

## 1. 会话失败：先自动重试，再只说人话
- 以前一次失败就把一大段**红色原始报错**铺在对话里，用户反馈「会把用户吓跑」。
- 现在：**失败先自动再试一次**（二次运行）；两次都失败也**只说一句人话**
  （能看懂、知道下一步），原始报错折进「技术细节」，需要排查再展开。
- 重试前会清掉上一次可能已经吐了一半的输出，避免「半截 + 完整」两份叠在一起。
- 用户主动取消、会话进程已退出这类情况**不重试**（重试只会再失败一次）。

## 2. 左右滑动更跟手
- 以前**必须拖过屏幕一半**才翻页（完全忽略甩动速度），而且动画写死 260ms。
- 现在：快速一甩就按方向翻页（看甩动速度），动画时长按**剩余距离**算（110–260ms）。

## 3. 设置页顺序重排
外观 → 云端大模型 → 本地大模型 → 模型轮换池 → 插件 → 手机权限 → 文件地址 → 关于
（「模型轮换池」保留在云端大模型旁边 —— 它管的是云端模型的轮换）

## 4. 每个模型加「匹配度提示框」⭐
- 三档：**🔴 无法运行 / ⚪ 勉强运行 / 🟢 流畅运行**，徽标旁**直接写明依据**
  （例如「内存 6 GB，这个模型要 8 GB」）。
- **两层数据**：进页面立刻按 **内存 + 机型 + 引擎是否随包** 给**预估**；
  点【测试】真跑一次后，徽标换成**实测**结论（带 tok/s 与首字延迟）并**落盘记住**。
- 判定阈值（都在一处、可调）：生成速度 < 5 tok/s 判红、5–10 tok/s 判白、≥ 10 tok/s 判绿；
  内存余量不足 2 GB、或 2 GiB 以上文件装在 8 GB 机上，判白。
- ⚠️ 【测试】会**真的把模型加载起来**（几秒到几十秒），并**切换当前正在跑的本地模型** ——
  所以是「点了才做」，不会自动跑。
- 图形 / 视频那几个模型会显示**🔴 无法运行**：这版**没随包** stable-diffusion.cpp 引擎，真跑不起来。
