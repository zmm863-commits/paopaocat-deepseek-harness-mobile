# 泡泡猫 DeepSeek Harness（DSH）手机版 v0.77

> **先把名字写全**：**DSH = DeepSeek Harness** —— DeepSeek 官方的智能体运行环境。
> 本 App 是它的**安卓手机版**：把整套运行时装进手机，一句话就能得到**真实文件**
> （`.pptx` / `.docx` / `.xlsx` / 图片 / 视频 / 剪好的片子）。

**这一版：修好 13 个问题、新增 5 项功能。**
最大的一件是 —— **Bot 团队住进手机**：建 Bot、建群聊、派活、看它干活，和电脑上是同一套界面。

> 口径：下面用 **MiB（1024 进制）**，括号里是十进制。计数口径与 App 内
> 「设置 → 关于 → 更新说明」里 **v0.77** 那一条**逐条对应**（同一份文案，18 条）。

## 一、新增：Bot 团队住进手机（5 项）

1. **Bot 团队上手机** —— 底部导航新增「Bot」：建 Bot、建群聊、给 Bot 派活、看它干活。
2. **模型设置新增「OpenCode Go」** —— 一个 Key 覆盖 DeepSeek V4 / GLM / Qwen / Grok 这一批模型；
   并把两类 403 分开说：**「你所在地区不开放」**与**「这把 Key 在该模型上没有权限」**。
3. **新建 Bot 时讲清「这是不是主 Bot」**，并且能直接给它选模型。
4. **Bot 页面补上「新建 Bot / 新建群聊」入口** —— 手机上找不到建团队的地方，现在一眼可见。
5. **运行环境升级到第 5 版**（内含 Bot 团队支持）—— 覆盖安装会自动处理，不用手动清数据。

## 二、修好的 13 个问题

**Bot 相关（8 条）**

1. **Bot 干完活生成的文件，资料库看不到** —— 团队工作区原来落在它自己那个目录。现在资料库把它**一并列出来**（带 `Bot/` 前缀）。
2. **Bot 页面点「添加文件」没反应** —— 网页里的文件选择必须由 App 接管。现在接上系统选择器，选完真的传上去。
3. **点 + 只看到几个图标、找不到「新建群聊」** —— 「发给：」面板被挤成几十像素，文字全被省略号吃掉。现在恢复整屏宽。
4. **Bot 的设置页在手机上几乎没法用、顶部按钮还叠在一起** —— 正文宽度写死「总宽减 198px」（手机上只剩 144px）。现在窄屏改成「上面两行栏目 + 下面整页」。
5. **「+」菜单那栏「定时任务」点开其实是设置页，而那页没有意义** —— 现在改名「设置」，点进去直接是「通用」；设置里那栏也拿掉了。
6. **从 Bot 设置页能一路打开 DSH 自己的设置**（改错会把 Bot 的模型/插件配置搞乱）—— 四条入口全关，点也跳不过去。
7. **Bot 读不到刚改的模型设置** —— 现在模型一变就重启 Bot 服务。
8. **从 Bot 列表点进某个 Bot、再按返回，直接跳回首页** —— 现在回到 Bot 列表。

**全局（5 条）**

9. **「会话建不起来」与「一直弹出 agent 请求执行操作」** —— 两个真因都修了：一处卡片缺协议字段；一处没配模型时权限预设跟着丢。
10. **浅色主题下输入框里的字看不清** —— 缺了一条正文文字样式。
11. **「拉取模型明显不对」** —— 一处判断会把已登记的模型清掉；顺带修了探活缺请求头、地区受限模型混进兜底清单。
12. **Bot 页面的配色不跟 App**（原来跟手机系统）—— 现在按 App 的设置走，换皮肤当场变。
13. **「Office 预览不可用。请在运行 DeepSeek Harness 的主机上启用文档预览服务。」** —— 改成「请到资料库查看文件」。

## 三、怎么装 / 怎么升

**全新安装**：下**完整包** → 点开 → 允许「安装未知应用」→ 安装 → 首次打开点「准备运行环境」。

**已经装过**：App → **设置 → 关于 → 检查更新** → 下载（可断点续传）→ 自动验哈希与签名 → 系统界面点「安装」。
**覆盖安装，数据都在**（会话、模型配置、Bot 运行环境）。签名对不上不会给你装。

## 四、已知限制（如实说）

- **只有 Android**（64 位、Android 7.0 以上），没有 iOS 版。
- **Bot 的「定时任务」这一版在手机上还用不了**（需要 DSH 的自动化插件，手机版没开）；定时任务请用 App 底部导航那个。
- **应用内下载依赖 GitHub 可达性**：国内直连有时不稳，退路是用浏览器下安装包。
- Bot 页面跑的是 ds-bot 的网页界面，个别桌面版交互在手机屏上仍可能显得挤 —— 这版修了最影响使用的几处，继续收。
