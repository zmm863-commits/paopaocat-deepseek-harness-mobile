## 0. 它是干什么的

手机上跑一个 **DSH 运行时的手机壳**：把电脑上那套 DSH（DeepSeek Harness）的运行时
（node + DSH 本体）打进 APK，在手机上直接跑，并通过 WebSocket 连你在电脑上起的
**桥（bridge）**，从而复用电脑上的模型与工具能力。

三种用法，按门槛从低到高：

| 用法 | 需要什么 | 能不联网吗 |
|---|---|---|
| **本机模型对话** | 下一份 `.litertlm` 模型（最大 2.4 GB） | 可以，全程离线 |
| **连电脑的桥** | 电脑上跑 `start-bridge.cmd` + 配对 | 需要局域网/内网 |
| **云厂商模型** | 任一厂商的 API Key | 需要联网 |

## 1. 第一次打开

1. 打开 App，底部有**五个 Tab**（从左到右）：

   | 位次 | Tab | 干什么 |
   |---|---|---|
   | 1 | **首页** | 开新会话；下面有 4 张**起始语卡片**（点一条就带着对应技能的指令开新会话），点「换一换」换一组 |
   | 2 | **创作台** | 之前叫「影视」。**入口页**列 6 个功能（生图 / 生视频 / 修图 / 口播·短剧 / 剪辑 / 画图表 / 小说改游戏 / AI 角色），点进去才是详情页，左上角「回创作台」 |
   | 3 | **资料库** | 工作区里的文件与产物；文本/图片/HTML/**视频音频**都能在 App 内看或播 |
   | 4 | **定时任务** | 让它在指定时间自动跑一件事 |
   | 5 | **设置** | 模型、外观、权限、诊断报告…… |

2. 首页若显示「**现在一个模型都没有**」，跟着它给的指引走：
   设置 → 模型 → 选一家 → 填 API Key → **测试并保存**。
3. 「测试并保存」是真发一次请求的：**通过**才算保存成功，失败会告诉你确切原因
   （Key 无效 / 额度不够 / 网络不通 / 结构不对），并且不会把配置写坏。

> ⚠️ 常见误会：以为"填了 Key 就等于配好了"。不是 —— 必须点「测试并保存」并**看到通过**。

## 2. 模型（设置 → 模型）

### 2.1 内置 5 家 + 自定义
- **Agnes**（有免费额度）/ **DeepSeek** / **Command**（聚合）/ **MiMo** / **LongCat**。
- 其它服务商（自建端点、其它云）：点右上「展开」再填，可以手写 Base URL。

### 2.2 Key 存在哪
只存在**系统安全区**（Android Keystore）：不写进 `models.json`、不进日志、
界面上也读不出来。分享日志时会自动脱敏（`API Key 已自动脱敏（会变成 ***已脱敏***）`）。

### 2.3 「获取模型」和「测试并保存」的区别
- **获取模型**：从厂商接口拉真实模型列表，你勾选要哪几个。
- **测试并保存**：真发一次对话请求。**它也会把模型自动登记进来**，
  所以"只点测试并保存"通常就够了。

### 2.3b 备用 Key（生图/生视频被限流时自动换一把）

**设置 → 模型 → Agnes（免费）** 那张卡里，Key 输入框下面有一块「**备用 Key（多账号）**」。

- 生图/生视频经常碰到 **429（被限流）** 或排队时，多一把 Key 就能在被限流时
  **自动换另一把**继续 —— 不用你手动重发。
- ⚠️ **限流与额度是按账号算的**：同一个账号下多建几把 Key **共享同一份配额**，
  加了也没用。所以这里要填的是**另一个账号**的 Key。
- 主 Key 仍然填在「API Key」那一栏（行为完全不变）；这里存的是**额外的**那些。
- 安全：只存本机安全区；界面上**不显示已保存 Key 的内容**，只显示序号。
- 相关的自动行为（0.59 起）：
  - 被限流 → 按服务端说的 `Retry-After` 等一会儿再试（没说就指数退避 2s→4s→8s…）；
  - 视频**排队期间**不会重复提交（重发只会让队列更长）；提示会告诉你已等多久；
  - **生图**遇到服务端临时故障（5xx）会自动重试；**视频提交**则一次都不重试
    （上一次可能已经建了任务，重试会重复扣配额）。

### 2.3c 创作台（生图 / 生视频 / 修图 / 口播·短剧 / 剪辑 / 画图表 / 小说改游戏 / AI 角色）

底部导航**第 2 项**。这是电脑上「泡泡猫的影视工具」的**手机版**。
**0.71 起它不再是一个大杂页**：点「创作台」先看到**入口页**（每个功能一行卡片 + 一句说明），
点其中一格才进**详情页**，详情页左上角有「回创作台」；标题也会变成「创作台 · 生图」这样。
（改这个是因为原来 6 个模式挤在一页、名字还叫「影视」，名不副实。）

- **生图**：写一句想画什么 → 选清晰度（1K/2K/3K/4K）与比例 → 点「生成图片」。
  可选**参考图**（最多 4 张）。
- **生视频**：写一句想拍什么 → 选时长（4/5/8/12 秒）与画幅 → 点「生成视频」。
  可选**首帧图**（给了就是图生视频）。
  ⚠️ 视频是异步任务：**几十秒到几分钟都正常**，页面会显示"已等多久"，
  等待期间**不会重复提交**（重发只会让队列更长）。
- **剪辑**（在**已有**视频上剪几刀，本机功能，不联网）：**剪一段 / 拼接 / 抽音频 /
  抽一帧 / 压小**。除「压小」和「精确剪」外都走**不重编码**，所以手机上剪一刀通常几秒完成、
  也不掉画质。两条要如实知道的边界：**不勾「精确剪」时，剪的位置会对齐到最近的关键帧**
  （可能差零点几秒到一两秒）；**拼接要求几段参数一致**，不一致时它会**直接报错**并让你勾
  「重新编码」，不会硬拼出一个画面中途变形的成品。
- **画图表**：44 种图型（流程图 / 时序图 / 架构图 / ER 图……），选一个例子或直接描述，
  产物是**自包含 HTML**（内联样式，不依赖任何外部资源），可以在资料库里直接打开。
- **小说改游戏**：把一本小说改编成**能玩的网页游戏**。这是一条**多轮流水线**
  （拆原著 → 比选方向 → 设计玩法 → 美术方向 → 构建 → 拿证据做 QA），
  点「开始一个改编会话」会带着指令开新会话。**别指望一轮做完**，它是分阶段来的。
- **AI 角色（实验）**：三张开局牌（审讯室 / 断电的太空舱 / 深夜电台），每张写清
  「谁演谁 / 在哪 / 你要办成什么 / 什么时候算完」——**每局都有目标和结束条件**，
  不是又一个聊天入口。如实知道的四条：角色现在**只能打字**（本机没有"朗读回复"）、
  记忆只在这一局里（开新会话就忘）、会话长了模型会漂、要上架得自己把握商店对
  **AI 生成内容**的要求。
- **修图**（本机功能，不联网、不花额度）：选一张图（相册，或直接从「作品」里选）→
  - **一键美化**：六个档位 —— 通透 / 电影感 / 人像 / 暖调 / 冷调 / 不美化，配**强度滑杆**
    （调色 `eq` / 锐化 `unsharp` / 磨皮 `smartblur` / 暗角 `vignette`，全在手机上跑，秒级）。
  - **擦除（去水印 / 去杂物）**：打开开关后，**直接按住预览图上的红框拖**到要去掉的东西
    上面（拖动即时响应）；下面那排「擦除位置的起点」（右下/左下/右上/左上/底条）
    只是**起点** —— 点一下会把框放回那个角，再用两个滑杆调框的大小。
    **预览里画的那个红框就是要被盖住的地方**（与真正执行的框是同一个数）。
    ⚠️ 它是**用周围像素把那一块盖住**，**不是恢复原内容**：纯色、平滑背景效果好，
    复杂纹理背景会看出痕迹。⚠️ 去掉**别人版权作品**上的水印有侵权风险（尤其发布/商用时）——
    这条只提示，判断在你。
    没有"瘦脸/大眼/换脸/真·修复"：那些需要人脸关键点或图像修复模型，App 里没有。
  - 产物直接进「作品」；页面下方给**原图 / 新图**对照。
  - 分工（别搞混）：**换风格、换主体、多图合成** → 用「生图」+ 参考图（走 Agnes，联网）；
    **只动这一小块、调色** → 用「修图」（本机 ffmpeg 滤镜）。
- **用哪个模型**：生图 / 生视频页顶部各有一行模型（默认是内置的 Agnes 免费模型），
  点「换一个」即可切换；候选来自「设置 → **图像 / 视频模型**」——在那边可以添加
  （模型名 / 显示名 / 端点 / 用哪家的 Key）。
  - **内置外部厂商端点**：添加图像模型时有一排预设 —— OpenAI / 智谱 GLM / 通义万相 /
    豆包 Seedream / MiniMax / 硅基流动，点一下自动填好**端点、建议模型名、厂家 id**，
    你只要在「云端大模型」里配好那家的 Key（厂家 id 要对得上，界面会提示）。
  - ⚠️ 边界：**图像模型**要支持 OpenAI 兼容的 `POST /images/generations`，
    而且本 App 是按 Agnes 的形状发的（`size` 用 1K/2K 档位、参考图放 `extra_body`）——
    多数第三方端点不认这两样，**能不能通要试**；
    **视频只认 Agnes 那套接口形状**（建任务 + 轮询 `agnesapi`），换厂商基本不通
    （所以视频**没有**内置外部预设）。
    失败会把上游原话显示出来，不假装成功。
  - 这份清单与会话模型**分开存**（`media-models.json`），改它**不会**影响你聊天用的模型；
    短剧的「每镜生成一张新画面」也用这里选中的图像模型。
  - 会话里也可以让模型直接用它：`node "$DSH_ANDROID_TOOLBOX/edit-image.mjs" 原图 输出 [--preset …] [--delogo x:y:w:h]`。
- **✨ 写专业点**：把一句话扩写成专业提示词（文生图 / 图生图 / 文生视频 /
  角色三视图 / 短剧剧本 / 数字人口播 六类专家）。这是手机上最省事的入口 ——
  不用自己凑"主体+动作+运镜+光线+风格"。
- **作品**（⚠️ **0.72 起不在创作台了，挪到了「资料库」右上角**）：**一个总库** ——
  创作台生成的 + **会话里生成的**图片/视频都收在这里，每张角上标着「来自影视 /
  来自会话」。图片点开可**双指缩放**；长按可**分享 / 保存到相册 / 删除**；
  视频与音频可以在 **App 内直接播放**（0.71 起）。下拉即重扫；数量超过 500 时
  只列最新的并在页面顶部如实提示。
- 被限流（429）时的行为与「设置 → 模型 → Agnes」里的**备用 Key** 联动，见 §2.3b。
- **口播**：把一段文稿变成带配音和字幕的视频。自动分段 → 每段配音 → 字幕画在画面上 →
  合成。可选一张「形象图」（不选就用纯色底）。
- **配音有四个来源，默认是手机自带的那个**：
  - **本机离线（零 Key）**：**0.73 新增**。声音**完全在这台手机上算出来** —— 不联网、
    不用任何 Key、免费。**代价如实说**：① 第一次要**下一次模型**（31.5 MB，装好后占约
    32 MB，界面上有下载按钮、**支持断点续传**，下完先核对 sha256 再解包）；② 音色**比云端
    机械**；③ 手机上的实际速度还没在真机上量过（我这边只有 x86 桌面数据：10 秒中文约 0.9 秒）。
    **为什么加它**：有的手机（比如 nubia/REDMAGIC 那台）**一个系统 TTS 引擎都没有**，
    而云端两家都要 Key —— 只有自带引擎才能保证"本机一定出得了声"。
    它有 174 个说话人（数据集编号，**界面上不编"男声/女声"**，只能试听挑一个），
    点「试听这一句」会把样音生成到**工作区**，去「资料库」点一下就能听。
    装不动也能**手动装**：把模型文件放进界面上写出的那个目录即可。
  - **系统配音（默认）**：用手机自带的语音朗读 —— **零配置、免费、可离线**。
    ⚠️ **但不是每台手机都装了语音引擎或中文语音包**（真机反馈过"没有可用的文字转语音
    引擎"）。遇到那种情况有两条路：去「系统设置 → 语言与输入 → 文字转语音」装一个
    引擎并下载中文语音包；或改用 MiMo / MiniMax。界面上也有「这台手机没有语音引擎？
    改用 MiMo（需 Key）」与「去设置里填 Key」两个按钮，一步就能到该去的地方。
  - **MiMo（可选）**：音色更自然，但**需要**你在「设置 → 模型 → MiMo」里先填一个 Key
    （`tp-` 开头的套餐 Key 会自动走套餐端点）。
  ⚠️ 这一版最初只支持 MiMo，经提醒后改成"默认系统配音"—— 因为这个 App 是给**网友**用的，
  不能假设他们注册过某家云 TTS。
- **短剧**：**一行一个镜头**，每镜一句配音 + 一张画面 + 一行字幕。
  打开「每镜生成一张新画面」会用**生图**按该行文本画一张；关掉则所有镜头共用同一张形象图
  （更快更省）。也可以先点「让「短剧剧本专家」写一版」生成分镜。
- ⚠️ 字幕是怎么来的：随包的 ffmpeg **没有** `subtitles`/`drawtext` 滤镜（NDK 里没有
  libass/freetype），所以字幕是 **App 用 Flutter 画在画面上**再合成的 ——
  好处是用手机自带中文字体，字形不会缺。
- ⚠️ 慢是正常的：配音 + 画字幕 + 合成**都在手机上做**，镜头多会比较慢，页面会显示进度，可随时取消。
- **这一版没有**：画布 / 封面（桌面重交互）。

### 2.3d 随包的 ffmpeg（口播 / 短剧的底层）

包里带了 **ffmpeg 7.1 + libx264**，用来做视频的拼接、转码、混音、加字幕。

- **怎么用**：在会话里让模型跑命令时，直接写 `ffmpeg -i 输入.mp4 …` 就能跑
  （环境里给 `ffmpeg` / `ffprobe` 定义了同名命令）；也可以用绝对路径变量
  `$DSH_ANDROID_FFMPEG`，或桌面端影视工具插件认的 `$AGNES_FFMPEG`。
- **能力**：`libx264`（H.264 编码）与 `aac`；常见容器（mp4 / mov / mkv / webm / m4v / gif）
  与常用滤镜（scale / crop / overlay / concat / subtitles…）。
- ⚠️ **手机性能有限**：转码/拼接比电脑慢得多，长任务要有耐心，别中途 kill 重来。
- ⚠️ **界面还没做**：口播 / 短剧的**按钮和流程**是下一版的事；这一步只是把工具装进包里
  （所以现在"缺 ffmpeg"不会再是拦路石）。
- **许可**：这个 ffmpeg 是 **GPLv2+**（含 libx264），App 的「设置 → 关于 → 第三方组件与许可」
  里有许可全文与相应源码地址；构建参数见仓库 `install/build-ffmpeg-android.sh`。
- **体积代价（如实说）**：装到手机上多占 **约 23.8 MB**；APK 从 100.7 MB 变成
  **约 111.6 MB**（+10.9 MB，压缩后）。用的是**共享库**方案（`ffmpeg`/`ffprobe` 共用
  8 个 `libav*.so`）—— 静态双份要多占 42.8 MB，共享后省了 19 MB。
- ⚠️ **字幕不是 ffmpeg 烧的**：这个构建里没有 `subtitles`/`drawtext` 滤镜（NDK 里没有
  libass/freetype）。字幕由 **App 自己用 Flutter 画在图上**再合成 —— 好处是用手机自带的
  中文字体（字形正确），比在桌面端到处找字体更省事。

### 2.3e 免费模型（无需 Key）—— 不用 Key，但是灰色用法

**设置 → 免费模型（无需 Key）**里有一个开关，**默认关闭**。

- 打开后，App 会在本机起一个小转发代理，把请求**按官方 CLI 的样子**发到
  **OpenCode 的匿名免费额度**，并把拿到的免费模型直接加进你的模型列表 —— **不用配 Key**。
  这不是宣传话术：那条通道本来就是**匿名**的，上游凭据是公开的字面量 `public`，
  由本地代理自己带上（所以模型选择器里这一组显示的是「**无需 Key**」，不是「未配 Key」）。
- ⚠️ **必须知道的代价**：上游的免费额度**只给它自家客户端用**，这条通道是**伪装**过去用它的，
  属于灰色用法，而且**随时可能失效**（上游已经收紧过两次）。所以：
  - **不承诺稳定**；失效时它会如实报错（并说清"这不是你没配 Key"）；
  - 它按**出口 IP 限流**，被限流时等一会儿；
  - 本 App **不做** IP 轮换、也不做反复重试（不拿它去刷额度）；
  - 用不到时请把它**关掉**。
- 开关旁边会显示**真实状态**（代理在不在跑、拿到几个模型、上次什么错），
  不是一个"已开启"的空壳。
- 拿不到模型时（上游不可用），App 会把这批免费模型**从你的模型列表里摘掉** ——
  免得你看到一堆"选了就连不上"的模型。

### 2.3f 办公文档：Word / Excel **能读也能写**（0.71 新增）

这件事以前做不到，因为办公文档那道坎一直是 **python**（python-docx / openpyxl），
而手机上只有 node。0.71 换了条路：`.docx` / `.xlsx` 的本质就是 **ZIP + 一堆 XML**，
而 node 自带解压 —— 所以现在**随包四个脚本**（纯 node，不装任何东西）：

| 想做的事 | 怎么说 | 边界（如实说） |
|---|---|---|
| 读 Excel | 「把这个表整理一下」→ 它自己会调 `read-xlsx` | **不解析公式**（读的是上次算好的值）、**日期会是序列号**、不读合并单元格 |
| 写 Excel | 「导成 Excel 发我」→ `make-xlsx` | 前导零（`007`）会保持文本；不做图表与条件格式 |
| **读 Word** | 「把这份 Word 里的正文提出来」→ `read-docx` | **只读正文**：页眉/页脚/脚注/批注不读；图片默认只在 Markdown 里标注位置（要真图加 `--extract-images`） |
| **写 Word** | 「给我一份 .docx」→ `make-docx` | 标题是**真标题样式**（Word 导航窗格、大纲、自动目录都能用）；列表是**真项目符号与编号**（所以 Markdown 里原本写的序号在 Word 里会被自动重编号）；不支持图片/页眉页脚/公式 |

> 老式的 `.doc` / `.xls`（没有 x 的二进制格式）**读不了**，如实说，请对方另存为 `.docx` / `.xlsx`。
> 本机**没有** Word / WPS / LibreOffice，所以"第三方办公软件能不能打开"最后一跳要靠你在手机上试。

### 2.4 轮换池
把几个模型排成一队：前一个被限流（429）或不可用时自动换下一个。
- 池子**不存 Key**，用的是各厂家各自的 Key。
- 流式响应一旦开始下发就不再切换（HTTP 头已发出，这是协议约束）。
- 会话的模型面板里，轮换池就是一项，名字即池名（数据上是 `rotate/<池名>`）。

## 4.5 移动桌面平台（手机当主机，电脑当浏览器）

**一句话**：手机跑 DSH 和设计站，电脑什么都不用装，浏览器打开一个网址就能用。
资料、模型、工具执行全在手机上，会话存在手机里。

### 打开

设置 → **移动桌面平台**（在「应用」下面单独一组）→ 选一张网卡 → 拨开关。

拨上去之后会依次显示四段进度，右边还有「已等 N 秒」：

```
准备运行环境… → 正在启动 DSH 与设计站… → 正在打开对外端口… → 正在接上设计站…
```

首启 **40~80 秒**（要解包运行环境），之后每次约 25 秒。这个时间是真的，
不是你网慢 —— 手机在起两个 Node 进程。

### 把地址拿到电脑上（三种方式）

面板上有三个按钮，对应三条路：

| 方式 | 适合 | 说明 |
|---|---|---|
| **复制网址** | 电脑和手机登录了同一个聊天/剪贴板同步 | 复制到电脑粘贴 |
| **扫码打开** | 笔记本有摄像头 + 扫码工具 | 弹出二维码 + **照着能敲的大字地址** |
| **手打** | 台式机（没有摄像头）、只想开一次 | 「扫码打开」里那串 `192.168.x.x:端口` 就是 |

> 二维码只解决一半场景：台式机没有摄像头。所以那一屏**同时**给了大字地址 ——
> 这不是兜底，是两条等价的路。

### 口令（token）

地址末尾带一段 `?token=…`，它是**身份凭证**：

- 没有它，同一张网里的任何人都能用你的 Key 调模型、翻你的资料库 —— 所以必须有；
- 它**会自动写进 cookie** 然后从地址栏消失（打开一次就够）；
- 面板上的「**重置口令**」会让电脑上已收藏的旧链接**立刻失效**，全部要重新拿地址；
- **别把这串地址发给别人**（它等价于把手机借给他用）。

### 断开之后会怎样

App 被系统回收、你把开关关了、手机换了网络 —— 电脑那页**不会白屏**：

- 浏览器显示一页说明：为什么断、去手机上哪儿重新打开（`设置 → 移动桌面平台`）；
- 它每 3 秒自己探一次；你把开关重新打开，**这一页会自己连回来**，不用手动刷新。

注意：**开关关掉时**底部导航那条通知（「电脑正在访问」）也会消失，那是正常的。

### 保活与通知

开关打开期间，通知栏常驻一条「电脑正在访问」。它的作用是把 App 进程提级，
免得你切后台十分钟后电脑突然连不上。关开关即消失。

### 限制（如实）

- 手机和电脑必须在**同一张网**（USB 网络共享 / 同一个 Wi-Fi）；**不能**在公网用；
- 只出 arm64-v8a 的包，x86 手机装不了；
- DSH 那条**只能**是这一条转发通道（不能直接绑网卡 —— 那样它自己的内部插件会连不上自己，
  整棵 profile 会起不来）；
- 设计站是第二条端口（面板上「设计站」那个地址），两条各有一个口令；
- 设计站起不来**不会**影响 DSH 网页本身，面板会写明原因。

## 6. 技能 / 专家

- **技能**：DSH 会扫两处真实目录 —— 用户级 `<DSH_HOME>/skills`、项目级
  `<项目>/.dsh/skills`。可以「新建」手写，也可以「对话生成」让模型写一个。
- **专家**：321 名专家 / 22 个分区。打开开关后，他的角色摘要会写进 `AGENTS.md`，
  DSH 会在**每个新会话的第一个请求前**注入。⚠️ **会占上下文**，别一次开太多。
  对已经打开的会话不生效，需要新建会话。
- **记忆**（设置 → 记忆）：见下面 6.1。

### 6.1 记忆：让模型长期记住你的事

**设置 → 记忆**（0.58 起）。在这里写下你希望模型长期遵守的偏好/约定，
例如"回答用中文、先给结论"、"不要用 emoji"。

- **它写到哪**：`$DSH_HOME/AGENTS.md` 里一段带标记的受管区块 —— 与「专家」开关
  **同一条注入通道**（DSH 内置插件 `dsh-agent-instructions` 在**每个新会话的第一个请求前**
  把它渲染进模型上下文）。页面上会显示真实路径，可自行核对。
- **什么时候生效**：`AGENTS.md` 是**会话开始时**读的，所以**对已经打开的会话不生效** ——
  要新建一个会话（和专家开关一样的时序）。
- **顺序有意义**：列表靠前的更"重要"。超预算时注入是**截断尾部**，所以记忆块被
  **放在 AGENTS.md 靠前的位置**，不会被排在专家说明后面挨刀。
- **有上限**：记忆单独限 **8 KB**（约 2600 汉字）。超了会**明确拒绝**并让你先删几条
  —— 不会静默丢弃。整个用户全局指令（含专家说明与"本机执行环境"那段）共享
  DSH 的 **64 KB** 注入预算。
- **和专家开关的关系**：两者都在 `AGENTS.md` 里，各占**各自的受管区块**，
  互不覆盖（写入时会先剥掉自己的旧块，其它内容原样保留）。你手工加在
  `AGENTS.md` 里的段落也不会被动。
- ⚠️ 内容里如果出现 App 自己的受管标记字样，会被**自动改造**（避免把块结构弄坏）——
  这是有意为之，不是你的文字被改了别的部分。

## 11. 出问题怎么办（诊断报告）

**设置 → 关于/诊断 → 生成日志**：

1. 报告会列出：版本、机型/芯片/内存、屏幕、系统语言、当前路由、模型数、
   **引擎在位与否**、各服务此刻的参数（上下文/后端/端口）、以及错误聚合。
2. 「分享运行日志」走系统分享面板（文件名形如 `泡泡猫的DSH-日志-v0.57-….txt`，**纯文本**）。
3. **脱敏**：所有进缓冲的文本都会过一遍脱敏 —— `sk-…` / `Bearer …` /
   `api_key|token|password=…` / URL 里内嵌的 `user:pass@` 一律替换成 `***已脱敏***`。
   证书指纹与文件 sha256 **故意保留**（配对/校验时你要肉眼核对）。

### 常见故障对照

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 发什么都**空回复** | 上下文窗口设得太小 / 模型本身不支持 | 换一个模型试；云端模型路由时到「设置 → 模型」重选一次（会重建路由）。**本机模型已无入口**（§3），不必再找那一步 |
| 「连不上模型端点」 | 网络 / Base URL 错 / 轮换池的本地代理没起来 | 回设置页切一次模型（会重启代理）；本机模型已无入口（§3），不必再找它 |
| 报「未配置模型」 | 模型没配或 Key 没通过测试 | 设置 → 模型 → 填 Key → **测试并保存** |
| 分享一个文件时提示「**这个文件所在的位置不允许对外分享**」 | 0.70 及更早的版本里，**默认工作区**不在系统的可分享名单里（一个真 bug） | 升级到 **0.71**（已修）；升级前可以先把文件挪到「资料库」里自己新建的工作区再分享 |
| 报 `no credential for provider route "local"` | 本地服务凭据没注入（历史 bug，已修） | 升级到本版；仍出现请报开发者 |
| 切了语言界面没变 | 历史 bug（`const` 子树不重建，已修） | 升级 |
| 桥连不上（`wss`） | 证书指纹不匹配 / 桥没起 | 用 `start-bridge.cmd`，核对指纹 |
| 语音输入用不了 | 系统里没有语音识别服务 | 装一个语音助手类 App；或先用文字 |
| 定时任务不触发 | 进程被杀 | 关掉本 App 的电池优化 |
| **发消息报「session/new 失败」，换哪个模型都不行** | **轮换池的名字是纯数字**（如「001」）—— 0.58 及更早版本会把数字池名写进运行配置，DSH 因此拒绝整份模型配置（坏的是整张表，不是某一个模型） | 升级到 **0.59**（已修）；或临时把池名改成非纯数字（如「001池」）即恢复 |
| 会话列表看不出这条会话是啥时候的 | 0.58 及更早版本的列表项显示的是序号、不是时间 | 升级到 **0.59**（现在显示「刚刚 / 12 分钟前 / 2026-09-28 14:02」）|

   `DSH_ANDROID_INCLUDE_LLAMA=1`。
3. **stable-diffusion（端侧出图）已整条删除**（2026-10-11，用户要求）：它是纯死重
   —— 界面自 0.45 起就没有入口，却占压缩后约 14.9 MiB / 未压缩 40.8 MiB。

7. 明文流量仍是允许的（局域网明文桥模式需要），已改成写明理由的策略文件，
   **没有**收紧成"只允许 127.0.0.1"（那会弄坏那条模式，而本机无法验证）。
