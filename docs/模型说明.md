# 大文件模型说明

仓库里不带第三方模型权重，原因有两个：克隆体积，以及许可证不同。
缺了它们，构建能过，但对应功能跑不起来。

## 人声分离（MDX-Net KARA_2，52.8MB）

用途：把人声和伴奏拆成两轨，本机运算。

模型来自 UVR（Ultimate Vocal Remover）生态，通过下面这个地址分发：

```
https://huggingface.co/AI4future/RVC/resolve/main/UVR_MDXNET_KARA_2.onnx
```

下载后放到 `app/assets/models/uvr-mdxnet-kara2.onnx` 即可。

国内网络可以用镜像：

```
https://hf-mirror.com/AI4future/RVC/resolve/main/UVR_MDXNET_KARA_2.onnx
```

模型的输入输出规格（构建时不需要，改代码时需要）：

```
input   float32  [batch, 4, 2048, 256]
output  float32  [batch, 4, 2048, 256]
```

四通道是立体声的实部与虚部，2048 个频点对应 n_fft 5120，256 帧约 5.95 秒一块。

推理走的是系统里已有的 `libonnxruntime.so`（离线配音功能带进来的那一份），
不需要另外装引擎。
