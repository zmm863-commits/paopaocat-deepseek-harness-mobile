# 你的手机里，装了一整个 AI 工作台

**一句话结论**：不是聊天机器人。你说要什么，它做完给你文件——幻灯片、图片、视频、代码，落在手机上，随时能打开、能分享。

## 一、它和普通 AI 聊天软件，差在哪

聊天软件是你问一句、它答一段，然后就没了。你要用那段内容，还得自己复制粘贴、自己排版、自己存文件。

这个 App 不一样：**它干完活，东西是落在你手机上的文件**。

你说「帮我做一份季度总结的幻灯片」，它给你的不是一段建议，是一个能直接打开的 `.pptx`。

你说「这份 CSV 里有啥问题」，它给你结论、给你图表，图也在。

**最实际的差别：它不用连电脑。**

DeepSeek Harness 本来是个电脑上的工具。这个 App 把整套东西塞进了安卓手机，算力、存储、网络全在手机上，出门在外拿手机就能干活。

## 二、别人做不到的三件事

### 1. Bot 团队：AI 帮你分工干活

这不是聊天，是带团队。

- 建 **Bot**：每个 Bot 有自己的角色和模型
- 建**群聊**：几个 Bot 拉进一个群，像带团队一样派活
- **派活**：说一句「这个交给谁」，它自己分下去
- **看它干活**：实时看到谁在做、做到哪一步
- 干完活生成的文件**直接进资料库**

和电脑版是同一套界面，不是手机特供版。主 Bot 管全局，从 Bot 各管一摊。

### 2. 泡泡猫助手：让 AI 替你点手机

这个可能是最特别的。

- **后台无头运行**：有一块看不见的虚拟屏，把 App 放进去截图、点、滑、输入，**全程不占你的屏幕**
- **免装 Shizuku**：打开手机「无线调试」，在 App 里输 6 位配对码就能用
- **录规则 + 规则库**：你在后台操作台点一遍，就录成一条规则；规则记的是**文字**不是死坐标，换手机、换分辨率也能用
- **会话里直接喊**：「泡泡猫帮我打开 QQ 音乐」「泡泡猫帮我执行 XX 规则」
- **一键关弹窗**：内置常用关弹窗文字库，自动点掉开屏广告、更新弹窗、领券弹窗；**绝不误点「更新 / 下载 / 支付 / 删除」**这类危险按钮
- **定时任务能挂它**：到点自动后台操作（打开 App / 跑规则 / 录规则）

不占屏幕、不打断你正在干的事。

### 3. 移动桌面平台：手机当主机，电脑当屏幕

手机跑 DSH，电脑浏览器打开就能用大屏和键盘。同一份数据，两边无缝接上。

- **地址真的固定了**：端口 + 网卡 + 口令三样都记住，电脑上收藏的链接不会第二天失效
- **扫码打开**：一屏给出二维码，外加能照着敲的大字地址
- **断线不白屏**：手机那边服务停了，浏览器会告诉你为什么断、去手机上哪儿重开；手机一恢复自己连回来
- 还附带一个**设计站**，在电脑上做图更顺手

## 四、它具体能干什么

**创作类**
- 做幻灯片：真出 .pptx，**12 种版式 + 自动排版**，不是一坨白底黑字
- 生成图片 / 视频：文生图、图生图、多图合成、文生视频、图生视频
- 配音：三档音色可调语速，还有**本机离线配音**
- 剧本导入、故事板编排

**干活类**
- 文档处理：摘要 / 改写 / 纠错 / 转格式
- 数据分析：CSV 进去，结论 + 图表出来
- 写代码：出来能直接跑
- 长文速读提炼：要点 + 时间线

**能力底座**
- 接多种云端模型，**一个 Key 全包**
- 三条免费通道，**不用配 Key**
- 子智能体：会话内部自己分工
- 专家团：**321 名专家 / 22 个分区**
- 技能库：**37 个技能**（短剧、网文、视频解说、小说改游戏等）
- 联网搜索

## 五、三重保障

**备份与恢复** —— 会话、记忆、模型配置、工作区文件打成加密包，换手机带走

**数据在本地** —— 会话记录、产出文件都在你自己手机上

**后台保活** —— 切出去任务不断（会挂一条常驻通知，安卓的硬规矩）

## 六、门槛在哪

**装完就能用。** 自带免费模型，不填任何 Key 就能聊、能干活。想要更好的效果，再去配自己的 Key。

**也说清楚它不擅长什么。** 手机性能有限，特别大的文件、特别长的任务会慢。它也不是什么都能做——你得把要求说清楚，含糊的指令它只能猜。

## 最后

手机上跑一整个 AI 工作台，这个想法听起来有点重。

但用起来你会发现，最爽的不是"手机也能跑 AI"，而是**你说完就走开，回来东西已经做好了**。

东西比你想的多。装上试试。
