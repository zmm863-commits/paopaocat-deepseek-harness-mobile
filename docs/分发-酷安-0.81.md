# 【自荐】把整个 DeepSeek Harness 塞进手机，离线也能跑 agent

## 先说它是什么

不是"手机遥控电脑上的 AI"，也不是套壳网页。

是**把完整的 DeepSeek Harness 运行时打进 APK** —— 内嵌 Node + 33MB 运行时包，装完就在手机里真跑一个进程。

关掉网络，它的界面、历史、文件都还在。

安装包 113 MB，原因就在这：运行时全在里面，装完不用再联网下东西。

## 三个我真用上的场景

**一、电脑不在身边的时候**

在客厅用手机开会话、让它整理文件、生成周报。数据不出手机。

**二、不想把资料传到别人服务器**

API Key 存 Android Keystore，会话和产物都在应用私有目录。

只有调模型那一步联网 —— 用本机模型的话全程断网。

**三、拿它当小主机**

这个 0.81 新加的：设置里拨一个开关，手机变主机，**电脑什么都不装，浏览器打开一个地址就能用**。

资料、模型、工具执行全在手机上，电脑只是个显示器。

## 0.81 修了一堆真机 bug

上一版那个「移动桌面平台」发出去基本不能用，这版全修了：

- 电脑打开地址只有一行 `authentication required` → 修好，而且**地址能长期用了**（以前一次就过期）
- 电脑上 Bot 页一直转圈「重新连接」 → WebSocket 握手被打断，修好
- Bot 页变成「只能查看」改不了 → 单实例锁误判，修好
- 面板有个按钮被挤到屏幕外 → 改成自动折行
- 启动白等 8 秒 → 改成两个源并发

## 实话实说的部分

- **Office 三个工具（读 Excel / 写 Word）还没挂上**，这条没修好
- 首次启动要 **40~80 秒**解包运行时，之后约 25 秒
- 只出 **arm64-v8a**，x86 手机和模拟器装不了
- 手机和电脑做「移动桌面平台」时**必须在同一张网**，不能公网用
- 装的时候有些国产 ROM（荣耀、红魔、ZTE 系）要你再输一次锁屏密码

## 怎么装

GitHub Releases 搜 `paopaocat-deepseek-harness-mobile`，下 `full-arm64-v8a` 那个 APK。

覆盖安装不丢数据。

点 APK 没反应的话，去文件管理器点，弹出「打开方式」时选「安装包查看器」—— 很多手机的默认打开方式被浏览器抢了。
