# 泡泡猫 DSH 手机版 v0.22 · 更新说明

> 本版就一件事：**修好「本地大模型能看到、却选不动」**。

## 问题
启动本地服务后，会话的模型选择器里**能看到**「本地大模型」，但点它**不生效**。

## 根因（一句话）
App 用一份"进程启动时吃进去的配置指纹"来判断**要不要重建会话**；
而这份指纹是从 `models.json` 算的，**没把本地模型算进去**。
于是点选本地模型时，App 认为"配置没变"，走了那条**只能在运行中的进程里切换已注册模型**的近路
（ACP `session/set_config_option`）—— 可本机模型是进程启动**之后**才出现的，
进程里根本没注册过它，切换必然失败。

## 修法
把本地服务状态（**端口 + 模型 id**）并入那份指纹。
现在：本地服务**启动 / 停止 / 换模型**都会让指纹变化 → 会话重建 → 新进程读到含 `local` 的配置
→ 选中即生效（端口也算进去，所以端口被占后换端口同样会重建）。
