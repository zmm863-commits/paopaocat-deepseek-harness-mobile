# 0.15

## 1. 语音：终于能用了

**之前的问题**：「按住说话」在**松手之后**才开始录音 —— 你对着手机说话的那整段时间里，
录音根本没开，采到的自然是一片静音，然后必然失败。

**所以麦克风权限怎么开都没用** —— 那从来不是权限问题。

**现在**：按住就开始听，松手才停。

> ⚠️ 这一条后来发现在少数机型上还不够（见 0.16 的语音两条）。

## 2. 会话更好用了（4 条）

- **对话能复制了**：长按用户消息或助手回复，就能选中、复制。
- **会话能改名了**：在工作区页里长按那条会话即可起名字。
  （名字只存在本 App 里 —— ACP 协议没有改名功能，DSH 那边不受影响。）
- **切到别的页面不再打断回答**：会话进程改由 App 统一托管。你去看资料库、
  去设置里改东西，正在生成的回答会**继续跑完**；首页顶部会出现
  「会话名（正在回答）」，点它直接回到那条会话。
- **可以同时开多个会话**：前一个还在跑，你就能回首页开新的，各自互不打扰。

## 3. 界面（2 条）

- **左右滑动切换页面**（首页 / 专家 / 资料库 / 定时任务 / 设置）。
  屏幕最边缘 24 像素内不响应 —— 免得和手机的边缘返回手势打架。
- **网格线调亮**：以前的网格只有 3.5% 透明度，在手机屏幕上等于看不见。
  这一版把它调亮并加了主次格线。
  > 这一条在 0.16 被推翻了 —— 你觉得网格不好看，于是**撤掉**。

## 4. 新增「手机权限」板块

在设置里。能看到**麦克风 / 定位 / 相册 / 通知**现在给没给，点一下弹系统的授权框；
另外收齐了「全部文件访问」这类特殊权限的入口。

**如实说明**：Android 没有「一键开全部权限」这种接口，特殊权限必须你自己去系统页面里开。

## 5. 图片现在真的能看懂了

**之前**：发图只是把文件路径丢给模型，纯文本模型只能回你「我看不到图」。

**现在**：App 内置了一条**免费视觉链**（不需要任何 Key），会自动把图片
转成文字描述再交给模型。

> ⚠️ 图片会上传到第三方服务，敏感内容别走这条路。

## 6. 会话产生的文件能留住了

以前退出会话再进来，产物列表就空了，只能去资料库翻。
现在按会话存下来，并且**知道是哪个会话产生的**。

## 7. 长会话助手

在输入框左边的 `＋` 菜单里。它会估算当前上下文用掉多少，
一键生成一份「交接笔记」插进输入框 —— 换新窗口接着做，不用把前面推倒重来。

# 0.16

## 1. 修好「让模型生成一个文件，产物里却看不到」

这是**两个 bug 叠在一起**，缺一个都修不好：

1. **识别文件名的规则会把绝对路径开头的 `/` 吃掉**。
   例如目标路径 `/data/…/会议纪要.txt` 被认成 `data/…/会议纪要.txt`；
   到了「核实文件真的存在」这一步，它被当成**相对路径**、拼到工作目录下面去找，
   **永远找不到**，于是被静默丢掉。
2. **工具「完成」的那一刻，通知里已经不带参数了**。
   App 之前只从**开始**的通报里取了「命令」一个字段、整个参数块都丢了。
   而像「写文件」这类工具，目标路径恰恰在参数里 —— 于是完成时无从获取，
   只能指望输出文本里恰好出现文件名。

**两个都修了**，并加了回归测试锁住。

## 2. 背景：撤掉网格线，整体提亮一档

深色界面设计的通行做法是两条：
**用近黑而不是死黑**（纯黑长时间看会累）、**用亮度分层而不是贴纹理**
（深色下阴影是看不见的，层次只能靠亮度差）。

所以现在**没有任何线条**，只有一层从顶部往下淡淡铺开的柔光 ——
画面有纵深，但不抢内容。底色也从偏死的黑提亮了一档。

## 3. 长会话助手的面板改成不透明实色

之前它是半透明的，和背后的内容参在一起、字看不清。现在是实色面板 + 顶部圆角。

## 4. 设置页把三块收成下拉

**模型 / 手机权限 / 文件地址** 现在点标题才展开（箭头会转个身），
收起后一屏能看全。外观 / 插件 / 关于保持原样。

## 5. 语音：又修了两个「卡住也不出声」的环节

1. **设备端识别同步报错时不回退**：少数机型不支持离线识别、或刚拿到权限还没就绪时，
   代码原本直接当成「没识别到」返回；而识别**回调**失败时却会回退到系统识别 ——
   两者不一致。现在统一都会回退。
2. **识别不到时的提示太含糊**：现在会顺带把**设备能力**查出来告诉你。

另外新增 **「语音输入」自检**（设置 → 手机权限 → 语音输入）：直接显示这台手机
到底有没有可用的识别服务、支不支持设备端离线识别、能处理识别的应用有几个。

> **如果自检显示「没有可用的语音识别服务」，那就是你手机系统里没装识别服务** ——
> 这种机型上语音怎么点都不会有反应。需要装一个语音助手类应用，或改用文字输入。
> 这不是 App 能绕过去的。

# 0.17

## 设置页六个分区，全部收成下拉

上一版只把「模型 / 手机权限 / 文件地址」收起来了；这一版**外观和插件也一并收起**，
「关于」也顺手统一 —— 否则它会是唯一一个摊开的分区，看着突兀。

现在进设置页只看到六行标题：**外观 / 模型 / 插件 / 手机权限 / 文件地址 / 关于**，
点哪一行才展开哪一行。

## 栏目名加粗加大

栏目行现在是这一页**唯一的视觉锚点**（内容默认收起）。
原来字号偏小、颜色偏淡，看着像"说明文字"而不是"标题"，找东西反而慢。
现在加粗、加大、提亮。

## 展开箭头带动画

展开箭头也一起放大了 —— 点开时它会转个身，一眼能看出当前是收着还是开着
（不是瞬间切换）。

# 0.18

## 1. 左右滑动改成「跟手翻页」

手指拖动时页面**跟着手指走**，松手再按惯性弹到目标页（有动画）。
之前是一松手就"啪"地换一页，很生硬。

## 2. 修好「只有滑到最后一页，才能双滑退出」

改成跟手翻页之后，屏幕最边缘的滑动一度被翻页手势抢走了 —— 而那里本该归系统的
返回手势。结果是中间几页从边缘滑只会"切页"，滑到最后一页（没得可切）才触发返回。

**现在左右各留出 32 像素不响应翻页**，从边缘滑动照旧是"返回"。

## 3. 「关于」不再收进下拉，一直摊开

它放的是公众号二维码、联系方式这类"想让人一眼看到"的东西，收起来反而要多点一次。

（上一版为了跟其它分区"统一"把它也收了起来 —— 那是我的判断失误。）

## 4. 「轮换池」改名为「模型轮换池」，并单独成一个板块

以前它缩在「模型」里面，得先把模型展开、再往下翻才看得到；
现在设置页里它和「模型」并列，一眼就知道有这么个东西、也能单独展开。

## 5. 其余五个分区保持下拉

外观 / 模型 / 插件 / 手机权限 / 文件地址保持下拉；
「关于」的栏目名与它们**同款样式**（加粗加大），所以看起来仍是一组。

## 怎么升级

直接**覆盖安装**即可，不用卸载、数据不丢：

* **0.15 / 0.16 / 0.17 / 0.18 的安装包签名，与你手上旧版是同一把证书**（`7aaf4448…d3cc17`）；
* 版本号是递增的（versionCode 15 → 16 → 17 → 18，versionName 0.0.18），Android 允许覆盖安装。

当前包体：`paopaocat-preview-0.18-arm64-v8a.apk` · 188MB · arm64-v8a · minSdk 24

```sh
sha256sum paopaocat-preview-0.18-arm64-v8a.apk
# 预期: ce814f197d2342db0adb5e82d31489cb4ea6233d7793c7a996c0829157d6ea0c
```

首次启动会解压内置运行时（约 26495 个文件），需要等一会儿；之后可离线使用。
