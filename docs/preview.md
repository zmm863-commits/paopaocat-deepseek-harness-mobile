## 一个真正跑在手机里的 AI 智能体

你有没有想过——**把整个 AI 智能体，装进口袋里**？

不是那种"手机上开个网页、后台还是别人服务器在算"的伪手机版。而是：**完整的运行时、完整的能力、完整的文件系统，全部在你自己的手机里**。除了调用模型这一步，它不依赖任何服务器。

这就是 **泡泡猫 DSH（Paopaocat DSH）**。

## 它本质上是什么

DSH 是一套能在本机跑起来的 AI Agent 运行时，能读写文件、执行任务、调用工具、维护多轮上下文。

我们做的事是：**把一整套 DSH 运行时原封不动地塞进了 Android 应用里**——内嵌 Node 运行时与全部依赖，首次启动自动解压到你手机的应用私有目录，之后**完全离线运行**（只有与模型对话时才需要联网）。

它不是"网页套壳"，也不是"远程桌面"。关掉网络，它的界面、它的历史、它的文件都还在你自己的手机上。

【图2·首页：`screenshots/round8_home.png`】

首页只有一个动作：**开始新会话**。没有多余按钮，也没有会误导你的假开关。

## 它现在能做什么（各板块实拍）

### 一、会话：真实的多轮对话

点开就是一条完整会话：流式回显、工具调用卡片、产物卡片、中断与继续。**多轮上下文是实测过的**——第一轮告诉它一个口令，第二轮它能准确答出来。

【图3·真实对话：`screenshots/round7_chat_clean.png`】

### 二、附件：拍照、相册、文件、语音，都是真的

这一块我们做得很实在：**全部走系统原生能力**，没有引入任何第三方插件。

- **拍照**：拉起系统相机，照片直接落进应用私有目录
- **照片／视频**：系统相册选择
- **添加文件**：任意文件，复制进应用目录后把**真实路径**交给模型——它能用读取工具真的读到内容
- **语音**：拉起系统语音识别，识别结果填进输入框，你确认后再发送

【图4·附件菜单：`screenshots/round6_attach.png`】
【图5·系统选择器：`screenshots/round6_picker.png`】

我们刻意**不做"上传成功"的假提示**。图片能不能被"看懂"，取决于模型本身的视觉能力——所以我们只把真实路径交给它，并在界面里如实说明。

### 三、专家中心：321 名专家，开哪个用哪个

内置**真实专家库：321 名专家、22 个行业分区**（工程、设计、市场营销、法务、医疗、游戏开发、安全……）。

每位专家一个开关，**开着的才会出现在会话的"专家中心"里**——而且这个开关是**真生效**的：它会把专家人设写进运行时的配置，模型真的会照那个身份来做事。

**技能**同样可玩：既能自己新建编辑，也能**通过对话让 AI 帮你生成一个技能**。

【图6·专家库：`screenshots/page12_expert_library.png`】

### 四、资料库：它产出的文件，都在这儿

AI 在会话里生成的所有文件（报告、脚本、清单、文档……）都会出现在资料库：

- **最近**：按修改时间倒序
- **我的资料**：按目录分组

搜一下就能找到。这是你自己的工作区，不是云盘。

【图7·资料库：`screenshots/round5c_library.png`】

### 五、工作区：多条并行，互不干扰

一个工作区就是一个真实目录。可以**新建、切换**，每个工作区有自己的会话历史。

会话列表**默认收起**，点一下才展开——界面清爽，也省得你一眼看到几十条会话发懵。

【图8·工作区：`screenshots/round7_workspace_expanded.png`】

### 六、定时任务：到点自己干活

「每天早上把昨天的提交整理成日报」这种任务，写一次就行。

支持**每天 / 工作日 / 每周 / 仅一次**，到点自动执行——复用与手动对话**完全相同**的执行通道。它还会把每次结果记进运行历史：成功、失败、以及"因为 App 没在运行而错过"，都如实记录，**不假装跑过**。

【图9·定时任务：`screenshots/round7_scheduled.png`】

### 七、设置：选一家服务商，填个 Key 就能用

模型接入做到最省事：内置 **DeepSeek 官方 / Command（聚合）/ LongCat（美团）/ MiMo（小米）** 四家，**端点已经预先填好**，你只需要填自己的 Key。

- 有「**获取模型**」按钮：直接从你的端点拉回真实可用的模型列表，点一个就选中
- 有「**测试并保存**」：它会**真打一次最小对话请求**（和实际对话走同一条通道）——通了才收起表单，显示"该模型已就绪"
- 所有报错都**翻译成中文**：额度用完、请求太频繁、Key 无效、地址写错……都会告诉你**下一步该做什么**，而不是甩一串英文 JSON 给你

## 关于隐私与安全

- **API Key 只存在手机的 Android Keystore 里**，不进命令行、不进日志、**不随安装包分发**
- 会话记录、生成的文件，全部在应用私有目录，其它应用读不到
- 除模型接口外，不向任何服务器上传数据
- **需要执行操作时会先问你**：Agent 想运行命令或改文件时，会弹出确认框，**告诉你要执行什么**（工具名 + 具体内容），看清楚再决定允许还是拒绝

## 一些我们说清楚的话

- **主题目前只有深色**。浅色主题需要把整套配色抽成变量，尚未开放——界面上它是**置灰并写明原因**的，不是"点了没反应"
- **后台运行受系统省电策略影响**。定时任务依赖一个常驻通知把进程留在后台；部分手机（尤其国产 ROM）仍会杀掉进程。App 会如实把错过的任务标成"已错过"
- 语音识别用的是**系统能力**，识别质量取决于你手机自带的服务
