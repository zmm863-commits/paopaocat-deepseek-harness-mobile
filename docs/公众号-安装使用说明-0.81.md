# 泡泡猫DeepSeek Harness 手机版安装使用说明

**一句话结论**：把电脑上那套 DeepSeek Harness 整个装进手机，手机自己就是主机。

导语：这篇讲三件事 —— 在哪下、怎么装（含国产 ROM 装不上的解法）、装完怎么用。看完能自己跑起来。

## 先说清楚：它和原版 DeepSeek Harness 是什么关系

原版 DeepSeek Harness 是在电脑上跑的：装 node、拉运行时、终端里敲命令。

这个 App 做了两件事 —— 一是**把整套运行时原封不动打进 APK**，让它在手机上真跑起来；二是**在它外面加了一层手机才用得上的东西**。

所以它既不是"原版 DeepSeek Harness 的手机壳"，也不是"把网页塞进 WebView"。

| 加了什么 | 是什么 |
|---|---|
| 移动桌面平台 | 手机当主机，电脑什么都不装，浏览器打开一个地址就能用 |
| 创作台 | 生图 / 生视频 / 短剧 / 口播 / 剪辑 / 画图表，把技能封装成点选 |
| Bot 团队 | 一个主 Bot + 若干成员分工，有独立的一套界面 |
| 资料库 | 文件与产物在 App 里直接看、直接播 |
| 定时任务 | App 内调度，到点自己跑 |
| 手机权限桥 | 读写手机文件、执行命令的两个 shim，绕开沙箱限制 |

**人话**：原版是引擎，这个是装了引擎、还配了方向盘和后备箱的车。

下面按"装 → 用 → 排错"讲，赶时间可以直接跳第二节。

## 一、三种用法，从省事到彻底离线

| 用法 | 需要什么 | 要不要联网 |
|---|---|---|
| 连电脑的桥 | 电脑上跑一次 start-bridge | 要，同一张网 |
| 云厂商模型 | 任一家的 API Key | 要 |
| 本机模型 | 下一份 .litertlm 模型文件 | **完全离线** |

**人话**：不想折腾就填个 Key；想彻底断网就下模型文件，但模型文件很大。

大多数人用第二种就够了，后面几节都按这条路线讲。

## 二、下载与安装

包在 GitHub Releases 页：

`github.com/zmm863-commits/paopaocat-deepseek-harness-mobile/releases`

最新是 **0.81**，文件名带 `full-arm64-v8a`，大小约 **113 MB**。

**为什么这么大**：里面塞了 node 运行时和 DeepSeek Harness 本体（约 33 MB 压缩包）+ 随包的 ffmpeg。

不是套壳，是完整运行时 —— 所以第一次装完能直接用，不用再联网下东西。

**装的时候会遇到的两件事**

**第一件：允许安装未知来源。** 点 APK 后系统会问，选「允许」就行。


**第二件：有些国产 ROM 要你再验一次身份。** 荣耀、红魔、ZTE 系这些，会要求输入锁屏密码才能装。


这是系统行为，不是 App 的问题。输一次就过。

**人话**：装个 App 还要输密码，不是中毒了，是厂商的安全策略。

**如果点了半天装不上**

先换一个「打开方式」。

很多手机上 APK 的默认打开方式被浏览器、网盘、解压工具抢了，点开只是预览。

到**文件管理 → 下载**，点那个 APK，弹出「打开方式」时选「**安装包查看器**」之类的安装器。

**人话**：不是包坏了，是系统把"点开 APK"这件事交给了别的 App。

## 三、第一次打开

打开后底部有六个 Tab：**首页 / Bot / 创作台 / 资料库 / 定时任务 / 设置**。

（老版本是"影视"，现在叫创作台。）

第一件事是**配一个模型**，否则发消息会没反应。

路径：设置 → 模型 → 选一家厂商 → 填 API Key → **点「测试并保存」**。

必须看到"通过"才算配好。

这个按钮是真发一次请求的：Key 无效、额度不够、网络不通、地址结构不对，都会明确告诉你哪一种。

失败**不会**把配置写坏，可以放心反复试。

**人话**：填了 Key 不等于配好了，测试通过才算。

**Key 存在哪**：存在手机本地（系统安全存储），不上传任何服务器。

## 四、六个页面各干什么

| 页面 | 干什么 |
|---|---|
| 首页 | 开新会话；下面四张起始语卡片，点一条就带着对应技能开会话 |
| Bot | 一个"Bot 团队"：一个主 Bot + 若干成员，能分工干活 |
| 创作台 | 生图 / 生视频 / 修图 / 口播短剧 / 剪辑 / 画图表 / 小说改游戏 / AI 角色 |
| 资料库 | 工作区里的文件与产物，文本图片视频都能在 App 里看 |
| 定时任务 | 让它在指定时间自动跑一件事 |
| 设置 | 模型、外观、移动桌面平台、诊断报告 |

**人话**：首页是聊天，创作台是干活，资料库是看结果。

## 五、手机当主机：移动桌面平台

这是 0.81 最值得说的一项。

**它干的事**：手机跑 DeepSeek Harness，电脑什么都不装，浏览器打开一个网址就能用。

资料、模型、工具执行全在手机上，会话也存在手机里。

**三步打开**

设置 → **移动桌面平台** → 选一张网卡 → 拨开关。

拨上去会显示四段进度，右边还有"已等 N 秒"：

```
准备运行环境… → 正在启动 DeepSeek Harness 与设计站… → 正在打开对外端口… → 正在接上设计站…
```

首启 **40~80 秒**（要解包运行环境），之后每次约 25 秒。

**人话**：这个等待是真的，手机在起两个 Node 进程，不是卡住。

**怎么把地址拿到电脑上**

面板上有三个按钮，三条路：

| 方式 | 适合 |
|---|---|
| 复制网址 | 电脑手机能互传文字 |
| 扫码打开 | 笔记本有摄像头 |
| 手打 | 台式机没摄像头，照着大字地址敲 |

二维码那屏**同时**给了能照着敲的大字地址 —— 因为台式机没有摄像头。

**地址后面那串 token 是什么**

它是身份凭证。

没有它，同一张网里任何人都能用你的 Key 调模型、翻你的资料库。

所以：

- 打开一次就会写进 cookie，地址栏里的 token 会自动消失；
- 面板上的「**重置口令**」会让电脑上收藏的旧链接立刻失效；
- **别把这串地址发给别人**（等于把手机借给他用）。

**地址为什么现在能长期用了**

以前那份地址**用过一次就废**，电脑上打开只剩一行：

`dsh web authentication required; reopen the URL printed by dsh web.`

原因是 DeepSeek Harness 内部的访问口令每次启动进程都重新随机生成，而手机上有好几件事会让它重启。

0.81 改成：手机发给你的地址里用**手机自己的固定口令**，由手机在后台换成当前口令再转给 DeepSeek Harness。

加上端口和网卡也被记住，于是地址终于能长期用了。

**人话**：以前是"一次性链接"，现在能收藏。

**断了会怎样**

App 被系统回收、你关了开关、手机换了网络 —— 电脑那页**不会白屏**。

它会显示一页中文说明：为什么断、去手机上哪儿重新打开。

而且每 3 秒自己探一次，你把开关重新打开，**这页会自己连回来**。

**人话**：断了不用刷新，它会自己回来。

**限制（如实说）**

- 手机和电脑必须在**同一张网**（同一个 Wi-Fi 或 USB 网络共享），不能在公网用；
- 只出 arm64-v8a 的包，x86 手机和模拟器装不了；
- 设计站是第二条端口，和 DeepSeek Harness 各有一个口令；设计站起不来不影响 DeepSeek Harness 网页本身。

## 六、遇到这些别慌

| 现象 | 原因与解法 |
|---|---|
| 电脑打开是 `authentication required` | 地址过期或复制不全。回面板重新点「复制网址」，注意尾巴上的 token 要完整 |
| Bot 页显示"只能查看，不能修改" | 旧版的单实例锁误判，0.81 已修（每次启动会清掉残留锁） |
| 电脑上 Bot 页一直"重新连接" | 旧版把 WebSocket 握手改坏了，0.81 已修 |
| 面板上有按钮跑到屏幕外 | 旧版窄屏会裁掉，0.81 改成自动折行 |
| 拨开关出现红字报错 | 旧版会重启 DeepSeek Harness 触发冲突，0.81 起不再碰 DeepSeek Harness 进程 |
| 启动时白等好几秒 | 旧版检查更新是串行等超时，0.81 改成两个源并发 |
| 想找 Bot 设置 | 右上角 ⋯ 菜单里，「重新启动」下面 |

**人话**：如果你手上是 0.79 或更早，上面一半的问题你都会遇到 —— 装 0.81 就对了。

## 七、怎么更新

两条路：

1. App 内：**设置 → 关于 → 检查更新**；
2. 手动：去 Releases 页下新的 APK，**覆盖安装**。

覆盖安装**不会丢数据**：会话、模型配置、Key 全都在。

**人话**：直接装新的就行，不用先卸载。

## 八、关于这个项目

它是怎么搭起来的，说清楚比较好 —— 这样你遇到问题也知道该往哪找。

| 层 | 是什么 |
|---|---|
| 界面 | Flutter 写的原生 App，不是网页套壳 |
| 运行时 | 内嵌 Node，DeepSeek Harness 本体以压缩包形式随包分发，首次启动解包 |
| 工具链 | 读写文件、执行命令靠两个自写的 shim，绕开 Android 的沙箱限制 |
| 媒体能力 | 随包带一份 ffmpeg，负责剪辑、口播、修图的底层 |

**人话**：手机里真的跑着一个 Node 进程，不是连着别人服务器。

**用了哪些现成的东西**

| 组件 | 许可 |
|---|---|
| DeepSeek Harness 本体（DeepSeek 官方） | MIT |
| ds-bot（Bot 团队那套） | Apache-2.0 |
| Flutter / Dart | BSD-3 |
| Node.js | MIT |
| ffmpeg（含 x264） | GPLv2+ |

**人话**：只有 ffmpeg 那块是 GPL，许可全文在 App 里「设置 → 关于 → 第三方组件与许可」里能看。

**源码**

**目前源码没有公开**，只提供安装包。

之所以先说清楚，是因为不少人在 Releases 页看到 MIT 许可文件，会以为整套源码都在。

这里更正一下：**那个 LICENSE 只覆盖仓库里已有的公开内容**，App 的代码暂时没放出来。

**人话**：能用、能装、能更新，但暂时不能自己编译。

以后要是放出来，会在 Releases 页和这里同时说明。

**有问题去哪说**

文章下面留言，或者仓库的 Issues。

装不上、闪退、某个按钮点不动，都欢迎报 —— 最好带上手机型号和系统版本，这样能省一轮来回。

**人话**：说清楚你在什么手机上、点了什么、看到了什么，比说“用不了”有用得多。

## 九、最后，说点实话

这版还有没修好的地方，我直说：

- **Office 三件套（读 Excel / 写 Word）目前在手机上还没挂上**，会话来着正常，但这三个工具用不了；
- 免费模型通道能用，但它走的是公共代理，**不适合放重要内容**；
- 首次启动那 40~80 秒是真实开销，暂时没法更快。

**人话**：主链路能用，边角还在补。

如果你装的过程中卡住，把现象告诉我；尤其是"点了没反应"和"装不上"这两类，多半是系统层拦的，不是你操作错了。
