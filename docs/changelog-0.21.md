# 泡泡猫 DSH 手机版 v0.21 · 更新说明

> 本版主题：**把模型分成两类（云端 / 本地），并修好本地模型的入口与观感。**

## 一句话
「设置」里原来的「模型」改名为 **「云端大模型」**，另开一个 **「本地大模型」** 板块；
同时修好"启动了本地服务，会话里却选不到它"这个 bug。

## 这一版改了什么

### 1. 模型分两类，不再混在一起
- **「云端大模型」**：原来叫「模型」，管的是连厂家 API 的那些模型。
- **「本地大模型」**（新板块）：手机本地跑的模型 —— 下载、从本地文件导入、启动服务、测速都在这。
- 名称统一：入口与页面标题都叫「本地大模型」（原来叫「端侧模型」，容易被理解成输入法或离线语音那类功能）。

### 2. 本地大模型页按「文本 / 图形 / 视频」分组
一页里混着对话模型与出图模型翻起来很乱。现在three组分开：
- **文本**：对话与理解类（含能看图的多模态模型）
- **图形**：出图类（Stable Diffusion / Sana）
- **视频**：出视频类（Wan2.1 / LTX-Video）

其中出图/出视频用的引擎（stable-diffusion.cpp）**这一版没有随包**，
所以这些模型只能先下载，界面上会如实写明「这版没带生图引擎，先下载」，
不会给一个点了必然失败的「启动」。

### 3. 本地大模型页按 App 的既有观感重做
第一版那页自定了一套字号（11/12/13/14/15 五档混排），还有几处没写字号的文本 ——
它们会走主题默认值再乘上「设置 → 显示」里的文字缩放，于是看起来"某几行大得不得了"。
现在统一走 App 既有词汇：玻璃卡、可折叠板块、入口行都用**与设置页同一份实现**
（`widgets/dsh_panel.dart`），字号只用 13（行标题）/ 11（说明）/ 12（按钮与脚注）/ 15（板块标题）。

### 4. 修好：启动本地服务后，会话里选不到它 ⚠️
**这是本版最重要的修复。** 会话里的模型选择器读的是 App 自己的模型库，
而本地模型只写进了 DSH 的配置 —— 所以「启动」之后，选择器里根本看不到它。
现在它会像「轮换池」那样，以 **「本地大模型」** 分组出现在选择器里（只在服务运行时出现）。

### 5. 「关于」的标题不再贴着卡片
标题与玻璃卡之间补上了与其它板块一致的留白（原来贴得很紧）。

## 装机信息
- 包名：`com.dshmobile.dsh_mobile`
- versionCode **21** / versionName **0.0.21**
- 签名与 v0.14–v0.20 同一把（`7aaf4448…d3cc17`）→ **可直接覆盖安装**

## 已知限制
- 本机推理需要 **Android 9 或以上**（GPU 后端的要求）。
- 生图 / 生视频引擎未随包（38.9 MB），功能待接。
- 模型清单里的 sha256 还没回填，目前导入/下载只校验文件大小。
- `docs/changelog-0.20.md` 里那个「端侧模型」的叫法，本版起统一为「本地大模型」。
