## 二、事项一：初始化提速

### 用户反馈

> 「为什么这一版初始化的时候特别的慢」（0.82 发布后）

### 根因（已确认，有代码依据）

启动流程里有一处 **`await`**：

```
启动
└─ await ZenChannel.refreshIfEnabled()      ← main.dart:490，阻塞在这里
   └─ enable()
      └─ 三条通道逐个探活
         · 0.81：只有 OpenCode 一条 ≈ 22 个模型 → 6 批
         · 0.82：接了 Kilo + OVHcloud ≈ 48 个 → 12 批   ← 数量翻倍
         每批 4 并发，单个超时 6 + 12 秒
         最坏 12 × 18 = 216 秒
```

**不是某个改动写错了，是模型总数从 22 涨到 48 的必然结果。**

「只列能用的模型」这条规矩（用户 2026-10-31 定）本身没错，但它的代价随通道数线性增长，而 0.82 恰好把通道数翻了倍。

### 已做的修复（代码在本地，未提交）

| 文件 | 改动 |
|---|---|
| `lib/local/zen_proxy.dart` | 探活并发 **4 → 12**；单个超时 **6+12 秒 → 4+8 秒** |
| `lib/data/zen_channel.dart` | ① 探活结果落盘 `zen-alive.json`；② 启动走**缓存快速路径**：有缓存就直接写配置并返回，探活转后台；③ 缓存超 24 小时不用（免费通道变动快） |

**预期效果**：48 个 → 4 批，正常 8 秒左右；有缓存时启动几乎不等。

### 验证

|---|---|

| `zen_channel_test` + `i18n_test` | ✅ 21 项全过 |

| **发布** | ⛔ 用户要求「先不要发布这个提速修复」 |

两边版本号暂时不同，这是有意为之，不是状态混乱。

等到决定正式发布时，再按下面的步骤走。

### 发布前必读（防踩坑）

本机已编好两个**不同**的 0.82 包：

| | sha256 前 8 位 | 内容 | 位置 |
|---|---|---|---|
| 线上 0.82 | `7154d20c` | 发布版（不含提速） | GitHub Release `v0.82` |
| 本机新版 | `2d85ce02` | 含提速修复 | `dist/paopaocat-dsh-0.82-v2-apk` |

⚠️ **线上 `update.json` 里的 sha256 指向 `7154d20c`**。不要直接拿 `2d85ce02` 覆盖 Release 资产，否则用户下载后校验失败。

### 发布步骤（决定要发时照这个走）

1. 提交 `zen_channel.dart` / `zen_proxy.dart` 到 git
2. 重算 APK 的 sha256 和字节数
3. 更新 `update.json`（版本号建议 0.83，或 0.82.1 视改动性质定）
4. 开新 tag / 替换 Release 资产
5. **刷 jsDelivr 缓存**（`https://purge.jsdelivr.net/gh/zmm863-commits/paopaocat-deepseek-harness-mobile@main/update.json`），否则用户最多等 12 小时
6. 真机验证：冷启动耗时、模型列表是否正常、探活结果是否正确

## 三、事项二：本地大模型攻坚

0.82 撤下了入口，代码与引擎原样保留。详细清单见 [开发周期-0.82](./开发周期-0.82-20261031.md) 第十九节，要点：

| # | 待办 | 难度 |
|---|---|---|
| 1 | **流式首字延迟**：真流式实现卡在一个 C++ 字符串转义错误上，没编译过。已修掉两个真 bug（重复加锁、chunked provider 引用悬空），最后一个语法错误待改 | P0 |
| 2 | **小模型吃不下 Agent 协议**：MiniMind2（65MB）能建会话但回复为空，吃不下约 7k tokens 的系统提示 + 工具。换 Qwen2.5-1.5B 待实测 | P1 |
| 3 | **线程数**：`llmconfig.hpp` 里 `thread_num` 默认 4，实测手机是 8 核 | P2 |
| 4 | **GPU 后端**：当前构建 `MNN_OPENCL=OFF` / `MNN_VULKAN=OFF`（纯 CPU） | P2 |

恢复入口的办法见 0.82 文档 `settings_tab.dart` 里的注释。
