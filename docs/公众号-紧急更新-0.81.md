# 紧急更新 DeepSeek Harness 手机版 0.81：修复移动桌面平台 BUG 及其他问题

**一句话结论**：0.81 是修 bug 的一版，重点是「移动桌面平台」终于能正常用了。

导语：上一版发出去后，真机反馈集中在我们最想推的那个功能上。这版把它和另外五个问题一起修了。

## 为什么要紧急更新

0.80 加了「移动桌面平台」—— 手机当主机，电脑用浏览器打开就能用。

思路没问题，但**发出去才发现它在真机上基本不能用**：

- 电脑打开地址，只有一行 `dsh web authentication required`；
- 好不容易进去了，Bot 页一直转圈「重新连接」；
- Bot 页还变成「只能查看」，改不了东西；
- 面板上有个按钮被挤到屏幕外面，用户根本不知道它存在。

这版全部修了。以下是每个问题的真实原因 —— 不是"优化了一下"。

## 一、地址打不开：只改了一个入口

真相是：面板里**有两处**会算出给用户的地址。

一处是拨开关那一刻，一处是离开页面再进来、或者 App 重启后恢复显示。

上一版只改了前者。后者还在用 DeepSeek Harness 自己的内部口令 —— 而那个口令**每次进程启动都重新随机生成**。

所以复制出去的地址，注定活不过一次重启。

| 你拿到的地址 | 尾部是什么 | 结果 |
|---|---|---|
| 旧版 | 48 位随机串 | 一次就过期 |
| **0.81** | **32 位固定口令** | **长期可用** |

**人话**：以前是"一次性链接"，现在能收藏了。

修法不是改那一行，而是把地址生成收敛成**唯一一个函数**，两处共用。

还加了一道源码门禁：以后谁再手拼地址，测试直接变红。

## 二、一直「重新连接」：我把它自己修坏了

上一版为了让每个请求都被改写，把所有请求的 `Connection` 头统一改成了 `close`。

而 **WebSocket 握手必须是 `Connection: Upgrade`** —— 被改掉之后握手直接失败。

前端表现就是：一直转圈，一直"重新连接"。

**人话**：车门锁上了，连钥匙也一起锁里面了。

现在的规则：

| 请求类型 | 处理 |
|---|---|
| 普通请求 | 断开连接（否则第二个请求会被拒） |
| WebSocket 升级 | **原样保留**，一个字不动 |

## 三、Bot 页「只能查看」：那个"另一个窗口"根本不存在

现象是顶部一行小字：

`Bot 团队已在另一个 dsh 中打开（Web or Desktop, pid 6982 on localhost）`

问题是我在手机上一个进程都没多开。

翻到 ds-bot 的锁实现才明白：它判断"是否被占用"时，**只看这个 pid 还活着没有**。

而 Android 会**复用 pid** —— 6982 早就不是我们的进程了，可它"活着"，于是永久判定被占用。

**人话**：门锁记住了上一位租客的钥匙编号，新租客发现"有人还拿着钥匙"，就再也不肯开门。

修法：每次启动前清掉这个残留锁。手机上本来就只跑一个 DeepSeek Harness，不存在真冲突。

团队数据一个字节都没动 —— 这条我用测试钉住了。

## 四、「重置口令」跑到屏幕外

那排按钮原来是横排，不会换行。

这版又加了「扫码打开」，四颗按钮在 360dp 宽的屏上装不下 —— 最后一颗被**静默裁掉**。

**人话**：不是显示不全，是整个按钮没了，所以你也说不出少了什么。

现在改成满了自动折行。窄屏、极窄屏都试过。

## 五、启动时白等 8 秒

检查更新原来是串行试源：先试一个，等它超时了才轮到下一个。

而你那边的第一个源基本每次都不通 —— 于是每次启动都白等一轮。

现在两个源**同时发**，谁先回用谁。

## 六、顺手补了个入口

对话框「+」里的「设置」在上一版做减法时被删掉了，入口就没了。

现在右上角 **⋯ → 设置**，就在「重新启动」下面。

点开直接是 Bot 设置的「通用」页。

## 怎么更新

两条路，任选：

1. App 内：**设置 → 关于 → 检查更新**；
2. 手动：去 Releases 页下新的 APK，**覆盖安装**。

覆盖安装**不会丢数据** —— 会话、模型配置、Key 都在。

| 项 | 值 |
|---|---|
| 版本 | 0.81（versionCode 249） |
| 包大小 | 113.0 MiB |
| 架构 | arm64-v8a |
| 最低系统 | Android 7.0（API 24） |

**人话**：直接装新的，不用先卸载。

## 还没修好的，我直说

- **Office 三个工具（读表格 / 写文档）在手机上还没挂上**，会话来着正常，但这三个用不了；
- 移动桌面平台的 WebSocket 修复已通过测试，**真机复验还没做完**；
- 首次启动那 40~80 秒解包时间，这版没动。

**人话**：主链路通了，边角还在补。

## 最后

如果你是被上一版劝退的，这版值得再试一次。

装的过程中卡住，把现象告我 —— 尤其是"点了没反应"和"装不上"这两类，多半是系统层拦的，不是操作错了。
