## 三、修掉的真 bug（点了必然失败那一类）

| 现象 | 真因 |
|---|---|
| 写作台 401 `api key invalid` | 手机模型名以 deepseek 开头，被误判成官方 DeepSeek，Key 发错端点 |
| 全部请求 400 `MissingSessionID` | OpenCode Go 每个请求都要 `x-opencode-session` |
| 错误一律显示成「去设置填 Key」 | 手机模式没有 Key 概念，却把上游原文改写了 |
| 「手机里还没有图像模型」 | 影视页模型存在 `media-models.json`，没导出给网页版 |
| 生图报 `i is not defined` | `cards.map` 回调漏了 index |
| 剪视频读不出时长 | 手机随包是 `libffprobe.so`，引擎只认 `AGNES_FFPROBE` |
| 短剧/MTV/背景视频一进页面就是死的 | 默认厂家落在只有文本模型的厂商上 |
| 口播「静态图」永远报缺图片 | 该面板没有选图入口 |
| Bot 页打不开（431） | WebView cookie 撑爆请求头（16KB），现已自动清理并重试 |

## 四、做减法

- **取消口播**：手机无 espeak-ng、也无 MiniMax / MiMo Key，配音本就跑不通 → 下架，不留假按钮
- **去掉设计站左上角「← 返回」**：出去走底部导航
- **网页版 Bot 页**：去「连接插件」；小金鱼菜单只剩三项；「+」菜单只剩两项；
  设置里清掉「定时任务」与「切换经典 Agent 模式」；断开提示改「连不上泡泡猫 DSH，请确认它还在运行。」
